# Warrior
 基于GAS的ActionRPG，使用PuerTS进行热更新

## 功能
实现了以下功能（主要依据历史提交记录）：
* Spawn Weapon
* Melee Combo System
    * Weapon Combat Component && Binding Input
    * Armed Locomotion
    * Attack Combo Chain
* Deal Damage
    * Add Enemy Characters
    * Init Attributes
    * Hit Detection
      * Toggle Weapon Collision
      * Hit Check
      * Process Hit && Notify Result
    * Custom Calculation
    * UI
